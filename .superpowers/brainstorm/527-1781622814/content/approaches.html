Proposed Fixes & Feature Design

3 bugs + 1 feature, grouped by approach

🐌 Fix #1: Speed Up UI Pipeline

A

Parallelize + reduce re-renders

Recommended. Fire loadMedia() and loadHelperStatus() in parallel at popup open. On job poll ticks, update only changed DOM nodes instead of renderHelperJobs() full rebuild. Add a 300ms debounce to the resize scan. Estimated: ~200ms→~50ms perceived latency.

B

Aggressive polling

Cut helper poll to 500ms, job poll to 500ms. Remove debounce. Simplest code change but wastes CPU/network on idle tabs.

🔘 Fix #2: Download Feedback

A

Optimistic UI + button guard

Recommended. On click: immediately disable the button, change text to "Starting...", show a job status line with a pulsing indicator. When the background responds, update with the real job ID. If it fails, show error and re-enable. Prevent double-clicks with a downloading Set tracking in-progress URLs.

B

Simple button disable only

Disable button on click, re-enable on response. No loading text, no optimistic job row. Minimal change but less informative.

📁 Fix #3: Folder Button

A

Fix isSafeDownloadPath + cross-drive support

Recommended. Replace the broken relative-path check with a simpler approach: verify the resolved path starts with the base download directory (case-insensitive on Windows). If the file doesn't exist yet (downloading), open the download directory instead.

B

Remove safety check entirely

Just open the path directly. Simpler but less secure — a crafted job could open arbitrary folders.

💾 Feature: Download History

A

Dual persistence + shared tab

Recommended (your choice). Helper writes helper-jobs.json on every job state change. On startup, loads history from disk. Extension caches last 20 jobs in chrome.storage for instant popup display. Helper tab shows merged view (active jobs + recent history). Dashboard shows full history with stat cards.

B

Helper-only persistence

Only persist to helper-jobs.json. No chrome.storage cache. Simpler but popup shows empty until helper responds (adds ~100ms latency).
